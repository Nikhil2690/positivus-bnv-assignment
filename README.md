

# Frontend Intern Task – Digital Marketing Landing Page

## Overview
This project is a responsive **digital marketing landing page** built using **React** and **Tailwind CSS**.  
I have built this project myself to showcase my **learning, skills, and professional experience** in frontend development.  
All design assets and references were taken from the **Figma file provided** as part of the task.

## Features
- Fully responsive layout for **mobile and desktop screens**
- Hero section, testimonials, working process, and footer components
- Clean, well-structured, and reusable code using React components
- Modern styling using Tailwind CSS
